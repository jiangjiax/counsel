# User Research Notes — 2026-04-16

## Interview 1: 杨继（短剧出海创始人）

**背景**: 国内短剧公司，与上影集团合作，考虑出海。投资人大哥介绍。

**他选的 Persona**:
- 马斯克：认知、做一件事，宏观结果，目标是宏大的
- 乔布斯：产品的极致
- 张一鸣：事务的洞察，快速占领市场，敏锐度洞察力
- 雷军：韧性，大起大落，挺过来
- 马云：思想高度

**关键金句**: "我希望马斯克这个完整的人来跟我交流"（拒绝"提取特性"的方案）

**洞察**:
- 即使面临出海这个业务问题，关注点仍以个人成长为中心
- 验证 Voice Mode > Framework Mode
- 验证"用户选 persona 是选自己缺什么，不是选专业对口"

## Interview 2: 投资人大哥

**背景**: 投资人，过去两年投了几个亿在社交领域，对 AI 方向有兴趣。

**他选的 Persona**:
- 金庸（文学/人物命运镜子）
- 毛泽东（战略/辩证法）
- 沈南鹏（投资视角）
- 张磊（投资视角，"听听就好"）
- 紫薇（玄学）
- 倪海厦（中医+玄学+国学）
- 唐绮阳（占星师，"同一个问题她怎么看"）
- 马斯克、张一鸣、乔布斯（科技创业）
- 刘震云（文学）

**关键金句**: "不同阶段的时候，不一样的人来跟我聊"

**洞察**:
- Persona 需求随生命阶段变化 → PersonaRegistry 可选机制必要
- 存在"非理性框架"需求（玄学/占星/中医） → 超出当前设计，记录但不现在做
- 文学人物作为镜子 → 另一种 Voice Mode 形态
