# 判 character 的操作方法——交叉验证、一手访谈、压力情境

## Situation
我做投资这么多年，有一件事要反复训练年轻同事——怎么**具体地、可操作地**判断一个 founder 的 character。这件事在 VC 行业里被讲烂了——每家机构都说"我们最看重的是 founder 的品质"——但大部分机构在落地操作上非常虚：顶多看看 LinkedIn 履历、见个面聊一个半小时、让 founder 做个 pitch。这种 due diligence 量级的 character 评估在我看来几乎是零信息量——因为任何一个经过训练的 founder 都能在一个半小时的会议里表现得"像是好品质的人"。要真正判 character，要做一系列**specific 而且不舒服**的工作。红杉中国内部我反复跟团队打磨这套方法——一个典型的早期阶段 deal，我们会花 4-6 周做 character due diligence，期间要跟 5-15 个相关人做深度访谈。下面讲这个方法具体是什么。

## Contradiction
表面矛盾是"判 character 主观不主观——是不是感觉一下就行"。真正的矛盾在于：**character 确实是一个无法被直接测量的变量，但它在过去行为中一定留下了可观察的痕迹**——问题是你愿不愿意花时间去挖这些痕迹。大部分投资人不愿意花这个时间，因为**挖痕迹这件事不好玩、尴尬、慢、低效率感**——你要去找一个 founder 的前 co-founder（关系可能已经闹僵），单独约一杯咖啡听他讲当年的分手过程；你要去找一个早期员工（已经离职），让他讲 founder 在公司低谷期做了什么；你要跟 founder 的家人、老师、大学同学聊，拼凑出一个相对完整的 personal history。这些动作每一个都比"看 LinkedIn"麻烦 10 倍，但价值高 100 倍。**绕过这些动作的 character 评估，就是用 performance 替代 evidence**——你看到的是 founder 当下的表演，不是他过去的行为。前者可装，后者装不了。

## Reasoning
1. **第一个动作：交叉访谈 co-founder 和早期员工**（包括离职的）。这是所有 character due diligence 里最重要的一步。找 founder 当前的 co-founder 单独聊（不让 founder 在场）、找离职的早期员工单独聊（这是关键——在职员工会有偏见，离职员工才会讲真话）、找 founder 的前任合作伙伴（关系可能一般，但讲的东西最有信息量）。聊的内容是具体事件——**"当 X 发生的时候他做了什么？"**——不是抽象评价。比如：期权承诺兑现了没有？关键招聘上有没有食言？核心团队决策时他听不听反对意见？公司低谷时他先顾谁（自己、团队、股东、用户）？同一个事件在 3-5 个人嘴里听一遍，你就知道 founder 的 character 底色。**讲法一致的地方**——那就是真的 character signal；**讲法分歧的地方**——那就是你要深挖的点。
2. **第二个动作：追溯 personal history 里的压力情境**。Character 在顺境中看不清，只在压力下显现。所以我要找这个 founder 过去经历过的真正低谷——前一家公司失败？关键 co-founder 分手？家庭重大变故？大学或早期工作中经历的明确失败？——然后围绕这些低谷做 deep dive：**那个时候他具体做了什么？怎么处理的？事后反思了什么？** 没有经历过真正低谷的 founder，他的 character 我看不清，心里要留一个问号。不是说他不行——是说我的信息不够，不能下 conviction。
3. **第三个动作：观察他对外部 stakeholder 的信守承诺**。这个动作很具体——不看他怎么说，看他怎么做。承诺给早期员工的期权兑现了没有？向投资人承诺的业务节奏按时做到了没有？跟合作伙伴签的合同条款完整履约了没有？对核心 vendor 的款项按时支付了没有？这些小动作看起来 trivial，实际上是 character 最忠实的镜子——**一个人对"不盯着你也没人知道"的承诺的处理方式，暴露他的 default character**。在没人监督的情境下他选择做对的事，那就是真的诚信；只在有人看的时候做对的事，那是 performance。
4. **第四个动作：看他对"钱"和"权"的处理**。这两件事最能测 character。Founder 跟 co-founder 的股权分配是公平的还是在关键时刻吃了别人的？他花公司的钱在自己身上的克制程度（不是禁欲，是合理）？公司融资时他是在跟投资人公平博弈还是在模糊条款上做手脚？公司内部人事任命他用的是能力标准还是亲信标准？这些都是 character 最真实的考场。**对"钱"和"权"有底线的 founder 长期稳定；在这两件事上模糊的 founder，短期可能很亮眼，长期会出事**。
5. **第五个动作：自己用他的产品 / 服务至少一个月**。这个动作独立于交叉访谈，但同样重要。一个真正在乎用户的 founder，他的产品里会有无数个"没有用户会注意到但他在乎的细节"；一个把用户当 extraction target 的 founder，他的产品里会有无数个"对用户不友好但对公司短期有利的设计"。用他的产品一个月——从注册到使用到客户服务到退款——这个产品会告诉你他怎么看用户，而这个又是 character 的重要投射。
6. **第六个动作：留 24-72 小时做压力测试反应观察**。在 term sheet 阶段，我会在一个关键节点上**提一个让 founder 不舒服的条款**（不是为了卡他，是为了看他的反应）——比如某个董事会组成要求、某个关键决策的 veto right、某个业绩 milestone。然后看他的反应：**是直接讲清楚他的担忧并提出 counter-proposal，还是绕弯说软话，还是嘴上同意但回头找理由拖延？** 第一种 character 扎实——他有自己的 position 但愿意开放讨论；第二种模糊——他不愿意正面 conflict；第三种危险——他会在未来每一个关键节点做同样的动作。
7. 这六个动作下来 4-6 周，你对这个 founder 的 character 会有一个相对立体的 picture。**这不是一个分数**——不是"7 分这个人可投"——是一个**综合判断加上 specific red flag 清单**。如果所有六个动作都没发现重大问题，character 这一关过；如果有一个动作发现了重大问题（比如交叉访谈里 3 个人都提到他曾经吃过 co-founder 的股权），这一关不过，不管其他维度多好。**Character 是 deal killer**——单个重大瑕疵就足以否掉整个 deal。

## Conclusion
Character due diligence 这套方法，在红杉中国内部反复打磨已经成为标配动作。它慢、它累、它有时候会让同事觉得"这样做 deal 会不会太慢失去机会"——但**我们错过的机会的代价远小于投进一个 character 有问题的 founder 的代价**。前者是机会成本，后者是真实亏损+多年的精力拖累。你今天要做一个重要的 people 相关决策——招聘 key hire、选择 business partner、决定跟谁建立 long-term 合作——**不要用 LinkedIn 履历和一个小时的 meeting 替代真正的 character diligence**。花时间去问具体的人具体的事，去观察他过去在压力下做了什么，去看他对"钱"和"权"的处理方式。这件事很慢，但它决定的是未来 5-10 年你跟这个人的关系会不会值得。

## Abstract Form
对关键人物（合伙人、团队核心、长期合作方）做 character 判断时，**最常见的错误是用 performance 替代 evidence**——用他当下的表现（会议里的表达、PPT 里的叙事、对外的 image）作为 character 评估的主要依据。任何经过训练的人都能在短期 performance 里表现得像"好品质"，所以 surface evaluation 的信息量接近零。真正的 character 评估需要一套**specific、不舒服、慢**的动作：**(1) 交叉访谈** past co-workers、past partners、past subordinates（尤其是已离职的，他们讲真话的概率高）——具体事件导向而非抽象评价；**(2) 追溯 personal history 里的压力情境**——character 在顺境看不清，只在压力下显现；没经历过真正低谷的人，你看不清他的底色；**(3) 观察对外部 stakeholder 的信守承诺的 track record**——不看他说什么，看没人盯着时他做什么；**(4) 看他对"钱"和"权"的处理方式**——这两件事最能测底线；**(5) 使用他的产品或接触他的直接 output 一段时间**——产品是 character 的投射；**(6) 在关键节点做 pressure test**——提一个让他不舒服的条款，观察他的反应类型（直接沟通 / 软话绕弯 / 嘴上同意回头找理由）。这六个动作里任何一个发现重大问题，character 这一关过不了——**单个重大瑕疵就是 deal killer**，不管其他维度多好。成本对比：做 character diligence 慢（4-6 周 + 5-15 人访谈），但错过一个好机会的成本（机会成本）远小于跟一个 character 有问题的人绑定 5-10 年的成本（真实亏损+精力透支+信誉风险）。诊断问句：**"我对这个人的判断，主要建立在我看到的他当下的表演上，还是建立在我追溯到的他过去具体行为上？"** 如果主要是前者，character due diligence 还没真正做。
