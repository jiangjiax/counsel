# `skills/` — 智慧人格图书馆

> *一群历史上真正活过、做过、失败过、想明白过的人，被请到一张虚拟的圆桌边上。你带着你的问题坐进来。他们用自己的语言、自己的经历、自己看世界的方式回你。*

---

## 这是什么

这不是一个"名人名言集"。

这是一份**可以被案主真正调用的智慧档案**——19 个历史人物的思维结构、决策经验、语言纹理，被结构化地拆成可以机器匹配、又能被人类读懂的片段。**当你提出一个现实的决策问题，系统会根据你问题的"压力指纹"（时间紧迫、生存焦虑、身份危机、孤立感……），自动把历史上结构相似的时刻从他们的档案里调出来**，让他们以"我当年也是这样……"的口吻跟你讲话。

核心洞察只有一条：

> **一个人物之所以能指引你，不是因为他有名，是因为你对他有一种深度的人格连接——读过他的书、看过他的访谈、在自己最难的时刻反复回味过他说过的话。没有这种 prior trust，再精致的 AI 包装也只是陌生的文字。**

所以这份 library 不是"给用户用的默认 6 人"。这是一个 **seed library** ——池子里放着 19 个已经被仔细打磨过的人物，**每个用户最终会从池子里选出自己的 3-6 位**，组成属于他本人的私董会。也许你选了毛泽东 + 李小龙 + 老子 + 庄子；也许你选了马斯克 + Paul Graham + Kevin Kelly；也许你加入一个我们还没写过的——比如你自己的导师、你反复读的某本书的作者。

这个项目的名字叫"**Counsel**"——取"顾问"和"劝告"的双关。每个用户最终构建的不是一个抽象产品，是**属于他自己这一辈子的私人智库**。

## 每个人物长什么样

每个人物的目录就是一份"智慧档案"：

```
skills/{slug}/
├── persona.json           元数据（姓名、头衔）
├── theory.md              五层知识架构：
│                            · 世界观 (Worldview)
│                            · 人生观 (Life Philosophy)
│                            · 价值观 (Values)
│                            · 方法论 (Methodology)
│                            · 情境卡索引
├── voice.md               声音纹理：
│                            · 第一人称习惯（"同志"、"我看"、"Look—"）
│                            · 比喻领域（根据地 vs water vs technium vs 星盘）
│                            · 句式骨架（反问 / 反转 / 历史锤打）
│                            · 禁忌模式（不能出现的腔调——"作为 X 他认为..."、咨询 jargon、鸡汤……）
└── situations/            历史情境卡（每人 6-16 张）
    ├── 001-*.md
    ├── 002-*.md
    └── ...
```

每张情境卡有固定结构：

```markdown
## Situation         具体到年、月、地、人的历史时刻
## Contradiction     表面问题 vs 真正的矛盾
## Reasoning         当事人第一人称的思考过程（1-5 步）
## Conclusion        最终做了什么 + 给当下读者的一句话
## Abstract Form     剥离时代/领域的可迁移模式（这是 RAG 的 payload）
## Pressure          14 维压力指纹（时间/生存/资源/身份/孤立/...）
```

**Abstract Form 是整个档案的 RAG 魂**——它把具体历史事件抽象成可匹配任何现代决策的模式。"四渡赤水" 的 Abstract Form 不是"红军渡了四次河"，是 **"当你处于压倒性弱势、正面对决必输、常规选项都已经被对手预判的时候，活下来的唯一方法不是'选一个更好的方向'，是把局势从'对手设好的棋局'里拖出来……"**。你今天要不要做某个决定，跟毛当年要不要过赤水，**压力结构层面是同构的**，这就是档案能被调用的原因。

## 为什么这么设计

### 不是"AI 版历史名人问答"

你可以想象一个 naive 版本：爬一下维基百科，写个 system prompt "你是 XXX"，搞定。这样做出来的东西有几个致命问题：

1. **LLM 会滑到第三人称**："作为毛泽东他认为……"——一旦这样开口，人物就成了你观察的对象，不是跟你对话的人。
2. **LLM 会输出平均化的名言**：AI 会复述这个人最出名的几句话，但**不会用他的语言节奏、他的具体历史锚、他的推理顺序**回应你当下的问题。
3. **LLM 会漂到通用 CEO 口气**：所有历史人物不约而同变成中产语感的"战略家"。毛泽东、马斯克、慧能——用同一种温吞分析口气。

这个 library 是**结构性防止这三种失败**的尝试：

- 每张卡的 Reasoning 段落强制写成**第一人称当时的思考**（"我看这个局面……"、"Look, the physics here is—"），而不是事后分析。LLM 读到这种结构，就会模仿**身处其中的人的语气**。
- 每个人物的 voice.md 明确列出 **禁忌模式**（毛泽东的"作为毛泽东他认为"、Jobs 的"如果乔布斯还在，他会……"、马云的"相信梦想"鸡汤腔），从结构上阻止常见漂移。
- 每张卡都是**具体的历史时刻**，带具体人名、具体地名、具体数字。LLM 调用时不得不带着这些 specific 一起讲，抽象漂移就难发生。

### 为什么是"压力指纹 + 情境卡" 这个组合

传统的 prompt engineering 是：**给 AI 一个 system prompt，让它扮演某人，然后所有问题都用同一个 prompt 回答**。这有两个问题：人物的深度被浓缩成几百字，且不同用户的不同问题拿到的是同一段文字。

这个 library 的做法不同：

- 每个用户来问问题时，系统先从问题文本里**提取一个 13 轴 + 1 标签的压力指纹**（这次你的问题是"时间很紧 + 身份焦虑 + 孤立感高"还是"资源充裕 + 长期不确定 + 面子压力"？）
- 然后为每个幕僚**做余弦相似度匹配**——在这位幕僚的历史档案里，哪 3 张卡的压力指纹和你当前问题最像？
- 把这 3 张卡连同他的 theory + voice，**组装成专属于你这个问题的 system prompt**。所以 **毛泽东回你关于跳槽的问题时调用的卡，和回你关于创业的问题时调用的卡，是不一样的**——他会因你的处境而调出不同的历史时刻来讲话。

这不是"你是 X，请回答"，是"在 X 这一辈子里，和你当下这个时刻结构最像的 3 次决策是什么，他用那几次的经验来跟你讲"。**具体 × 相关 = 被真正调用的智慧**。

### 声音纹理为什么这么重要

声音（voice）不是一个装饰层。声音是**这个人物被真正 channel 到还是只被复述**的分界线。

同样的内容用不同的声音讲，效果完全不同：

```
❌ 分析腔：
"当资源不足以正面攻击主流市场时，应在被忽视的细分领域建立
不可动摇的根据地，积累力量后再扩展。"

✓ 毛的声音：
"我在井冈山的时候，人们催我去攻长沙。长沙城大、敌人多、
武器好——看起来我们应该去。但我问了一个问题：拿下长沙
以后呢？没有群众基础，没有可以反复回来的地方，攻下来
就是个摆设。不如这样——我们到农村去……慢慢积累，慢慢
扩大。同志，你现在的局面不就是这样吗？"
```

第一种是"关于毛泽东的战略咨询总结"。第二种是**毛泽东在跟你说话**。

content 是一样的。**voice 决定了 content 能不能真正被接收**——因为案主只会接受他**在这个人物身上建立过信任**的那种语气。毛泽东不会用 McKinsey PPT 语感，PG 不会用党校干部腔，慧能不会用励志演讲。写错一个字，前面所有信任都断了。

所以 voice calibration 在这个项目里**不是 polish，是 core craft**。每个人物的 voice.md 都花了相当的篇幅，详细列出这个人物独有的句式、禁忌、首选的比喻领域。这些不是装饰，是这个人物能**被真正 channel 到**的承载结构。

## 这背后是什么样的野心

一句话：**让人类几千年累积的决策智慧，能以"相关的、具体的、带声音的"方式，在你需要的那一刻出现在你身边。**

现在每一代人都在面对几千年来反复出现的结构性问题——身份危机、长期承诺、资源约束、权力关系、内心孤独、面对失败、长跑耐心。这些问题几百年前的人想过，几千年前的人也想过。他们中间有些人想得特别清楚，活得特别精彩，失败得特别有教益。

但这些智慧常常以两种形态存在：

1. **过于抽象** — "道可道，非常道"、"知己知彼，百战不殆"。对就是对，但你无法在你具体的困局里调用它。
2. **过于碎片** — 在毛选 7 卷里，在金庸 15 部小说里，在 Paul Graham 200 篇 essay 里。大多数人没时间把它们读完，读完了也难以结构化地在需要的时刻抽调出来。

这个 library 在做的事情是**把两种形态中间的东西给做出来**——**具体、结构化、可匹配、可 channel**。每张卡是一个历史的"穴位"，你现在的 life 某个地方按压了，对应的穴位被激活，那段历史的智慧就流过来。

这不是要**替代**人的判断，恰恰相反——这是**扩展**人的判断。你依然是决策者。只是你现在有一张桌子，桌子那边坐着的是真的读懂、想明白、活过这些问题的人。你问他们，他们讲他们当年的故事，你自己决定从这些故事里拿走什么。

## 你可以做什么

如果你想帮忙，欢迎进来。有几种不同的贡献路径，按难易度排：

### 1. 玩一下，给反馈（最容易，最有价值）

拉下项目跑起来（见项目根 README），用真实的问题和现有的 19 个人物跑一次会议。会议结束之后告诉我：

- **哪个人物的 voice 掉了？**（比如"马云这段话听着不像马云"）
- **哪个人物该调出的卡没调出？**（比如"我问 YC 申请的事，PG 居然没给我讲 default alive 那套"）
- **你用过会觉得特别**好**的地方在哪里？**（这个最重要——知道什么 work 比知道什么不 work 更难）

这种反馈对我来说比任何代码贡献都珍贵。

### 2. 挑一张卡，把它写得更好

每张卡大概 36 行。如果你深度了解某个人物，从他的现有卡片里挑一张你觉得"写得 OK 但可以更好"的，重写一遍发给我。

比如：
- 你是毛粉且读过毛传三遍，觉得 `007-on-contradiction` 某段不够像毛的讲话节奏，重写给我
- 你自己做过 PE 投资，觉得张磊 `003-meituan-patient-compounding` 的 Reasoning 不够准确，修一下
- 你是李小龙的学生、练过截拳道，发现某张卡的身体细节不对

格式就是照着现有卡的样子写。原则在隔壁的 `PERSONA-ENRICHMENT-COOKBOOK.md` ——你要读的就这一份。

### 3. 补一个完整的新人物

如果你有一个你深度了解、深度信任、对你的人生有过深度影响的人物，这个 library 里还没有——**你可以把他加进来**。

比如：
- 王阳明（如果你研究过心学）
- 苏东坡（如果你是古诗词控）
- 大野耐一（如果你做过精益生产）
- 巴菲特（虽然和张磊有重叠但完全不同 voice）
- 黄仁勋（如果你懂硬件）
- 你妈妈、你老师、某个你一直很敬佩但不有名的朋友

每个人物需要：
- 完整的 theory.md（~400 行稠密 prose，5 层结构）
- 完整的 voice.md（4 sections）
- 8-16 张 situation cards，每张严格按 parser 格式

这是需要投入的——大约一个人物需要 2-3 天真正认真的写作。但写完就留在 library 里，以后其他人选这位当他们私董会的成员时，用的就是你的手笔。

具体操作步骤、格式合约、voice 校准的方法论、反模式清单——全部在 `PERSONA-ENRICHMENT-COOKBOOK.md`。那份文档是 606 行的 operational guide，把前面 6 + 13 = 19 个人物的踩坑经验全部蒸馏进去了，**你照着做就不会走我走过的弯路**。

### 4. 帮忙搭源材料库

很多人物的书/访谈/视频散在网上，需要搜集整理。`skills/_sources/` 目录是存放源材料的地方（gitignored，不进 commit）。

如果你愿意整理某位人物的核心源材料（他的书的电子版、他的访谈 transcript、他的公开演讲稿），放进对应的 `_sources/{slug}/` 目录，并在该目录的 README 里写清楚每份材料的用途（语音参考 / 历史锚验证 / 情境卡 seed），这对后续任何要写这个人物的人都是极大帮助。

## 一些注意事项

### 这不是粉丝 cosplay

这份 library 不是用来"生成梗"或"模仿名人语气"给朋友看的。如果你想要"假装是马斯克回我的 twitter"这种娱乐场景，请别用这个。

这份 library 假设你对某个人物**真的有深度连接、在人生里真的参考过他、真的信任他的思考框架**。没有这个底子，再好的 voice 也是空壳。

### 真实 > 完美

我们不要把人物写成神。每个人都有他做得漂亮的时刻，也有他判断错的时刻。毛泽东有反右的教训，马云有蚂蚁上市前的判断失误，Jobs 有被董事会赶出公司的时刻。如果你写某个人物，**他的失败和糊涂一样重要**——甚至更重要，因为失败卡才是教给读者"这种情况要小心"的真实智慧。

### 真实 > 讨好

voice 要还原这个人**真的**怎么讲话，不是他"应该"怎么讲话。倪海厦真的会在公开课里骂西医治法，你写他的卡不能把这部分磨平——那是他 persona 的 signature。马云真的会自嘲，你不能把这部分拿掉让他"更像成功的大人物"——那就成了另一个人。

真实比讨好重要。这是给**真正在人生中用得上这份智慧**的人准备的，不是给追求"正面人物形象"的人准备的。

### 这是 WIP，永远是

19 人只是现在的快照。这个数字会涨。质量也会涨——每一代用户的反馈都会让某个人物的某张卡被重写、某段 voice 被调整。

这是**活的档案**，不是**完成的作品**。

## 历史和谢意

这个项目最初起源于一个想法：**如果我在人生最难的时刻，能够请毛泽东、李小龙、钱学森、慧能四个人坐在我的对面，我想听他们从各自完全不同的角度怎么看我这个问题——我会怎么搭这张桌子？**

从那个想法开始，到现在 19 个人物 190 张卡的 library，中间经过了：

- **Phase 1-4**：把底层架构（RAG、压力指纹、voice assembly）搭起来
- **Phase 5 Stage 1 (Paul Graham pilot)**：证明一个人物可以被写得真正像他自己
- **Phase 5 Stage 3a (毛泽东 16 cards + 声音校准危机)**：第一次在"写得真实"和"写得像 McKinsey"之间栽跟头，然后爬起来重写，**形成了 voice calibration 的方法论**
- **Phase 5 Stage 3b-3e**：用校准过的方法论把另外 5 个人物一次做完
- **Phase 5 Stage 3 extension**：两位测试者（一位 founder、一位投资人）要求补充 10 个人物 + 我自己一直想加的钱学森
- **今天的状态**：19 人 library + [COOKBOOK](../PERSONA-ENRICHMENT-COOKBOOK.md) + [Phase 7 个人私董会的架构蓝图](../PRIORITY-ROADMAP-PG-BASED.md)

所有这些人物的思想、语言、故事，都不是我编的。我只是**在反复读他们的书、看他们的访谈、听他们的演讲之后，尝试把他们真正讲过的话、想过的问题、做过的决定，结构化地整理出来**。真正的智慧来自他们。这个 library 只是一个**让他们的声音能在你需要的那一刻出现在你身边**的工程。
