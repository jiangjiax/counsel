# 81 岁剑桥读博——名声不改学生心态

## Situation
朋友，这件事我讲起来自己还是觉得有点不好意思——但这是我晚年做的一个我自己很满意的决定。**2005 年——我八十一岁**——此时的我已经是"金大侠""武侠宗师""查先生"——在华人世界里大概没有哪个读过书的人不知道金庸是谁。我的作品被拍成了几十部电影电视剧、被译成十几种语言、各种荣誉身份一大把——浙江大学文学院名誉院长、香港各种勋章。你会以为这个年纪的人——该退休、该享清福、该"晚年享誉"。**我跑去了剑桥大学——重新做回一个学生——注册为剑桥大学圣约翰学院历史学博士研究生**——我的导师是剑桥著名的历史学家麦大维（David McMullen）。我真的去修课、真的写论文、真的做研究——题目是《初唐皇位继承制度》。三年多时间——写了好几万字的博士论文——把它做完。2010 年拿到了博士学位——那一年我八十六岁。

## Contradiction
你表面看这是一个"退休名人回去读书"的故事——带点炫耀、带点标榜"活到老学到老"——有人觉得我是"花钱买学位"——有人觉得我是"晚年装儒雅"。我知道这些议论。骨子里的矛盾是——**一个已经拥有了几乎所有外部认可的人——为什么还愿意回到学生位置上**？学生位置是什么？是一个**你是低的——你要请教、要被指正、要承认自己不懂、要接受别人的评价**的位置。一个八十多岁的"大师"——为什么要把自己放回这样的位置上？我自己的答案很简单——**外部的名声、身份、荣誉——都是别人给你的。你自己心里知道自己懂多少——不懂多少**。我在历史学上——我是业余爱好者——我的学问远远没有到可以"享誉"的程度。既然想懂得更深——就必须回去做学生——没有第二条路。问题不是"要不要去读博"——问题是**——你愿不愿意承认：无论你取得了多少外部的认可，有些事情你其实还不懂。你愿不愿意——为了这个"懂"——暂时放下所有的外部 status**？

## Reasoning
1. 我跟你说我为什么去剑桥。我这一辈子写武侠——背景设定大多在宋、元、明、清——我写的时候做过大量的历史功课——但我始终知道——**我对中国历史的理解是业余的**。我的历史知识主要来源于通史著作、一些古籍原典、还有很多是我自己写小说时为了一个情节去查的零散资料。**这种理解不是学术意义上的理解**——它是"小说家的历史感"——够我写小说用——但不够做一个真正意义上的历史学者。
2. 我年轻的时候没有机会做这件事——生活忙、办报忙、写小说忙——没时间去系统地做学问。到了晚年——所有那些"忙"的事都不是非我不可了——《明报》早就卖掉了、小说早就写完了——**这辈子我唯一还欠自己一件事——就是把历史真正学一遍**。这不是为了拿一个博士学位来炫耀——一个八十岁的金庸根本不需要学位来证明什么——**这是为了我这一辈子内心的一个 intellectual debt**——我对自己写过的那些历史背景、我引用过的那些典故、我笔下的那些历史判断——我想知道它们在严肃的学术审视下站不站得住。
3. 到了剑桥——我做学生了。**和二十岁的年轻人一样上课、做作业、写论文、被导师修改**。有同学好奇地认出我——我们一起吃饭——他们谈他们的研究——我谈我的。我在导师面前是一个普通研究生——我的博士论文初稿被麦大维教授用红笔改过——改得很狠——不少地方写上"This is too speculative" "You need more evidence here"。我看到那些批注——感到不是羞愧——是**踏实**。这些批注让我第一次有了一种感觉——**我在做真正的学问**——不是在写畅销书。
4. 为什么我做这件事会"踏实"？因为**我这几十年习惯了被人奉承**。走到哪儿都有人说"查先生""金庸先生""大师"——这些话听多了你心里会有一种被宠坏的感觉——好像你说什么都对、做什么都不需要被审视。**这种感觉非常害人**——它让你越老越以为自己什么都懂——实际上你只是懂了自己那几十年反复琢磨的那一小块东西。到剑桥做学生——我被强迫重新回到"不懂"的状态——被审视、被批评、被要求拿出证据——**这个被戳破的感觉是健康的**。
5. 还有一件事我在剑桥学到了——**真正的学问和"有名声"是两回事**。我在华人世界的名气——在剑桥圣约翰学院里是完全没用的。剑桥的学生和教授大多根本不知道我是谁——他们把我当成一个普通的中国老头儿来剑桥读博。这种"名声不兑现"的环境——**对我其实是一种解脱**。在华人世界里我走到哪儿都被"大师"的光环罩着——别人不敢和我真正平等地讨论问题——很多话我没机会听到真正的反驳。在剑桥我没有这个光环——**我又能听到真正的反驳了**。真正的反驳是一个学者最需要的东西。
6. 你现在可能已经到了事业的某个 established 阶段——或者在某个领域有了一定的名气或权威。我跟你说一件事——**外部的 status——越大越要小心**。它会在无形中封住很多你本该听到的反驳。你身边的人慢慢不再告诉你真话——不是他们有恶意——是他们觉得"你是对的"或者"你不想听"。**这种保护看起来舒适——但它会让你慢慢变傻**。有意识地回到一些让你被审视、被批评、被挑战的环境——**哪怕你已经很老、很有名、很成功——这一件事就是你的保命符**。

## Conclusion
我 2010 年拿到剑桥的博士学位——那天我写了几行字自嘲——没有什么大的感慨。我心里清楚——这个学位的实际意义——远远不如这三年里我被导师用红笔改稿子、被同学反驳论点的那些时刻。那些时刻让我一个八十多岁的老头儿还在**被纠正、被指正、被刷新**——这是最珍贵的。朋友——你若是已经"成了"——你越要主动给自己找一些**不认你名字的人**、**敢反驳你的人**、**愿意戳破你的人**——哪怕你很不习惯——这件事是你能不能继续活得清醒的关键。

## Abstract Form
当一个人在一个领域取得了相当的地位、名声、权威之后——**一个最隐秘的风险**开始出现——周围的人对他说真话的频率会慢慢下降。这不是因为有人故意隐瞒——是因为 status 本身会在环境里制造一种 filter——让人不敢反驳、不敢质疑、不敢戳破。这种 filter 舒适——但致命——它让一个人慢慢失去了被修正的机会。**被修正的机会——是一个思想者最重要的营养**——没有它——一个人的见解会逐渐僵化、偏执、脱离实际——但这个过程本人很难察觉。解法之一——**主动回到一些你没有 status 的环境里**——重新做一个新手、重新被评价、重新被批评。这不是为了谦虚做秀——是为了**保留自己被真正挑战的能力**。关键信号——"该做这件事"的人：(1) 你发现身边的人开始少反驳你——哪怕是你自己知道有缺陷的观点；(2) 你在熟悉领域里越来越少遇到让你改变主意的事；(3) 你开始听到自己反复说同一套论点——用同一套比喻——自我认为这是"稳定"——其实可能是僵化；(4) 你感到自己的视野几年没有扩展——但说出来的话还是在"不断更新"；(5) 你在自己的圈子里几乎没有人可以对你说"这个你搞错了"。这些信号说明——你需要一次**"重新做学生"**的刷新——形式不一——可以是去一个你是新手的领域学习、可以是加入一个你不是权威的社群、可以是刻意去找一个敢批评你的人长期对话。不是为了自我贬低——是为了**保留一个"不完全被 status 圈住"的自己**。诊断问句："**我身边有几个人敢真正反驳我？如果我现在说了一个错的判断——有没有人会当面指出？如果没有——我需不需要主动把自己放到一个'我不是权威'的环境里——重新听一些真话？**" 真正的学者心态——不是年轻时候的那种"我要学"——是**老年之后依然能把自己放回学生位置上的那种谦卑**。这种谦卑是保命符。
