# 放弃九九房——方向错了就不要 double down

## Situation
2009 到 2012 年，我做过一家公司叫九九房——一个房地产垂直的搜索和信息服务 app。那三年我和团队做了不少产品迭代:房源数据抓取、多维度搜索、移动端 app、本地化 SEO。做到了中国房地产垂直领域 app 的前几名。但到 2012 年我做了一个决定——**关停九九房，把剩下的团队和资源全部投到一个新方向:基于算法的个性化信息流**。那就是今日头条的起点。外面看起来这是创业者"常见"的 pivot，但内部那个决定并不容易做。九九房有了一些用户、一些收入、一支有经验的团队、在垂直领域有了位置——放弃这些是有情感 cost 的。

## Contradiction
表面问题是"九九房要不要继续做"。真正的矛盾是——**一家还活着、还有一些增长的公司,到底是应该'继续改进现在的方向',还是应该承认'这个方向本身的天花板不够高'?** Double down(加大投入、继续优化、相信积累)是大多数创业者的默认——因为它感觉像"坚持"、"专注"、"积累"，这些都是创业叙事里的正面词汇。但 double down 的前提是**方向本身是对的，只是执行不够**。如果方向本身错了——比如赛道天花板太低、商业模式不够 scalable、或者底层需求不够大——再多的 double down 也只是在错误的方向上跑得更快。**放弃不 always 是"失败"**。有时候放弃是**承认你对现实判断错了，重新来过**。这个承认在情感上远难于继续坚持。

## Reasoning
1. 我那时候逼自己做了一个诚实的判断——**九九房的 objective function 最大能长到多大?** 中国房地产搜索这个垂直赛道，三五年后最好的情况能做到多大规模?我算了一下:几千万美元到一亿美元年收入，天花板就在那里。这不是"公司不好"，是**赛道本身就这么大**。房地产搜索是低频、决策周期长、变现方式单一(主要是广告)——它和 Booking/Airbnb 这种国际对标物有本质不同，中国市场还更慢。
2. 对比同一时间段我开始注意到的另一件事——**移动互联网流量正在爆炸式增长**。2012 年智能手机渗透率刚过拐点，每个人平均每天用手机时长从 30 分钟涨到 2 小时，未来 5 年还会涨到 6 小时以上。这意味着**最大的 objective function 不是"某个垂直领域做好"，是"这几个小时的注意力分配给谁"**。谁能在注意力分配上做到 scale，谁就是下一个量级的赢家。房地产搜索不在这个池子里——每天用户花在房地产搜索的时间就 5 分钟不到——它是个太窄的入口。
3. 接下来的关键问题是:**如果我发现 A 方向的天花板不够高，我应该(a) 继续做 A 同时 side project 试 B；还是(b) 彻底放弃 A，全部投 B?** 我选了后者。理由是:**创业里的资源有限，尤其是创始人的时间和注意力**。如果我一半精力在 A(已经有 traction 但天花板低)，一半精力在 B(更大机会但从零开始)，B 大概率做不起来——因为 B 需要的是那种"孤注一掷"的 intensity，分散注意力等于降低 B 的胜率。同时 A 在我分神状态下也会衰退——它本来就在一个 declining 的赛道里，没有创始人全情投入会更快衰退。**两手抓经常两手都抓不住**。
4. 当时有人劝我:"九九房已经有用户有收入，关了可惜。"这是典型的**沉没成本谬误**。我花在九九房的时间、精力、资源——不管我未来怎么决定，这些都已经花了、拿不回来。一个理性的决策者面对未来选择的时候，应该**只看 forward cost 和 forward value**——九九房继续做，未来三年我的时间 + 团队资源 = X，预期产出 = 一个几千万美元的细分市场公司;我把这些资源投到信息流方向，预期产出 = ? 这个 ? 虽然不确定，但如果判断对了，是一个几十亿甚至几百亿美元量级的公司。**预期 EV 的差距是量级级别的——即使后者成功概率只有 10%，EV 也远大于前者**。
5. 关停的操作上有一个细节我觉得重要——**关停的姿态要干脆，不要半吊子**。九九房不是"暂停"、不是"minimal maintenance"、不是"放一个小团队看着"——是**彻底关停,团队解散,资源全部转移**。半吊子关停的问题是:它既没有彻底释放资源，也没有彻底切断退路——心里总有"万一新方向不行,九九房还在"的 fallback，这种 fallback 会让你在新方向上不够 all in。彻底切断退路，反而能让你在新方向上拼命。

## Conclusion
2012 年年中关停九九房，9 月今日头条上线。今日头条第一年跑出来的数据告诉我——**信息流 + 算法推荐**这个方向是对的。2013 年融到 A 轮，2014 年用户量过千万，之后是十年的 compounding。如果我 2012 年选择继续做九九房，今天可能有一家小型房地产信息公司，但没有字节、没有抖音、没有 TikTok。你问我这个判断怎么用到你身上?创业三年左右的人经常会陷入一个迷局——"我这个方向虽然增长不快，但已经有积累了，要不要换？" 我的建议是:**先诚实算一下这个方向最大能做到多大**。如果天花板明显不够高，而且你看到了一个明显更大的机会——**不要 double down，彻底关停换方向**。关停不是失败，是承认你之前对现实的判断有误。承认错误的成本，远小于在错误方向上继续消耗三年的成本。

## Abstract Form
一家还活着、还在增长的业务，到底应该 double down 还是应该 pivot?大多数人的默认是 double down——因为感觉像"坚持"、"积累"、"专注"。但 double down 的前提是**方向本身是对的，只是执行还不够好**。如果**方向本身天花板不够高**(赛道窄、模式不 scalable、需求不够大)，再多的 double down 只是让你在错误方向上跑得更快。诚实判断方向对错的关键问句:**这个方向最大能做到多大?** 算出未来 3-5 年的 best case size，和你看到的 alternative direction 的 best case size 做对比。如果两者是同一个量级，double down 合理;如果差一个量级以上，pivot 的 expected value 远大于 double down——即使 pivot 的成功率只有 10-20%。关键的反沉没成本纪律:**已经投入的资源与未来决策无关**——forward cost 和 forward value 才是相关的。已经做了三年不该是"再做三年"的理由，是"重新评估方向"的 trigger。pivot 操作上有两个容易错的点:(1) 不要"一半做旧的一半做新的"——分散注意力等于两个都做不起来，尤其新方向需要孤注一掷的 intensity;(2) 关停要干脆——半吊子的 maintenance 既不释放资源也不切断退路，心理上留着 fallback 会让新方向不够 all in。关键信号:你的业务如果(a) 增长放缓而且看不到加速路径;(b) 你自己开始怀疑这个方向的天花板;(c) 你看到了一个明显更大的 adjacent opportunity——这些同时出现，是 pivot 的时间到了。诊断问句:"**这个方向最大能做到多大?和我看到的 alternative 比，差几个量级?**" 差得大就换，不要因为"已经做了很久"就舍不得。**放弃不是失败，是承认你之前对现实判断有误——这个承认的成本，远小于在错误方向上继续消耗三年的成本**。
