# 格力举牌——价值投资需要时的 operator-grade 介入

## Situation
2016 年，高瓴开始在二级市场买入格力电器的股票。格力电器当时已经是中国白色家电行业的龙头之一，董明珠作为董事长带领格力长期保持行业领先。但 2016-2019 年这段时间，格力面临一系列治理层面的 dilemma——控股股东（格力集团）的持股结构如何演化、管理层跟大股东之间的利益如何 align、格力如何从单一空调业务向多品类 + 国际化转型。2019 年，高瓴作为主要参与方，通过珠海明骏（高瓴领衔组成的 consortium）**以约 417 亿人民币受让格力集团持有的格力电器 15% 股权**，成为格力电器第一大股东。这不是单纯的二级市场持有，是深度介入公司治理结构的 operator-grade 动作——包括 board composition、管理层激励、长期战略方向的 deep engagement。

## Contradiction
表面问题是"价值投资是不是应该只买入持有、不介入公司运营"——这是 classic Graham/Buffett 式 passive value investing 的 framing。真正的矛盾不是 passive vs active 的二元选择。真正的矛盾是：**当一家公司的 intrinsic value 和 market price 之间的 gap 不只是市场情绪导致的，还有 governance structure 或 strategic direction 层面的真实问题时，作为 value investor 你是做什么？** 一种选择是 "wait and see"——相信 time 会解决一切；另一种选择是——**用 capital 进入 ownership position，然后作为负责任的股东参与治理改善**，让 intrinsic value 真正 unlock。前者是 passive value investing；后者是 **engaged value investing** 或者 **operator-grade value investing**。两者都叫"价值投资"，但行为完全不同。中国这种市场，很多 great company 的 intrinsic value 需要 engaged ownership 才能 unlock——单纯 passive 持有容易被 structural friction 消耗掉。

## Reasoning
1. 我看格力这笔投资的起点不是 PE ratio——是 **business fundamentals**。格力的 core business 在空调行业有 unbeatable 的 operational excellence——研发、供应链、成本管控、渠道网络——这些是 organization-level capability，是**真正的 moat，不是一时的**。这条业务基础扎实，cash flow 稳健，在白电行业里 ROIC 长期 top。这是 value investing 的底。
2. 但我同时看到几个 issue：**(a) governance structure 需要优化**——当时的 ownership structure 让管理层和股东 interest 的 alignment 不如理想 clean；**(b) 战略 evolution 的 velocity 不够**——格力在新品类、国际化、数字化这些方向上有机会但 pace 被 governance friction 减慢；**(c) 长期激励机制需要升级**——要让真正在 create value 的 management team 有 proper long-term incentive。这三个 issue 都是可以通过 engaged ownership 改善的。如果我是 passive holder，这些 issue 会长期 persist，intrinsic value 和 price 的 gap 也会长期存在。如果我作为负责任的大股东进来，有机会帮助 unlock。
3. 做这个决定之前，我反复问自己一个问题——**作为 engaged owner 介入一家已经很优秀的公司，是不是 arrogant？** 我的答案是——**不 arrogant，if I'm coming in as thinking partner not as controller**。格力的 operational excellence 是董明珠和她的 team 40 年做出来的，我没有那个 capability 也不应该 take over。我能做的是在 strategic direction、governance structure、long-term incentive 这几个 layer 上提供 perspective——从 value investor 的 cross-industry pattern library 来帮公司看得更远一点。Control 不是我的 objective，alignment 才是我的 objective——让所有股东（包括管理层）的 interest 都 align 在 long-term value creation 上。
4. 进场之后的动作，我 primarily 做两件事：**(a) 把 long-term incentive 机制建起来**——让管理层和核心员工有 meaningful 的 long-term equity stake，让他们的 interest 真正跟股东 long-term 对齐；**(b) 在 strategic direction 上做 thinking partner**——在多元化、数字化、国际化这几个方向上，我不告诉董总怎么做，我 share 我看到的 cross-industry pattern（比如我投过的其他制造业公司是怎么做的、国际同行的 best practice 是什么、哪些 trap 要避免），最终决策是她和 her team 的。这种 engagement 是 catalyst 式，不是 commander 式——一个 engaged owner 越界到 take over operation 的那一刻，公司的 agency 就被破坏了。
5. 更深一层，这件事教给我一个 operating principle——**value investing 不是被动持有 ETF，是一种 responsibility**。你作为一家公司的大股东，有 fiduciary duty 去帮它变得更好，不只是去 extract return。这种 responsibility 意味着：在它需要的时候 engage，在它不需要的时候 back off；在 governance 层面做贡献，在 operational 层面保持克制；跟管理层建立长期 trust-based relationship，在关键决策上提供 perspective，但不 override。**这种 engaged ownership，是我对"价值投资"这个词的理解——value investing is not a spectator sport**。

## Conclusion
高瓴在格力的 engagement 是一笔长期投资，outcome 会被时间慢慢揭示。但这件事对我来讲的 value 不只是 financial return，是 validated 一个方法——**当一家真正 great company 的 intrinsic value 因为 governance friction 或 strategic friction 没有被 fully unlock 时，作为 engaged owner 进去做 catalyst 是 value investing 的 legitimate 应用**。不是每个 deal 都该这样做——大部分 deal 应该是 passive hold——但在一些 specific situation，engaged ownership 是 create additional alpha 的方法。这件事给你的启示是——**你手里在做的一件长期 commitment（投资、工作、合作关系），当你发现这件事的 potential 没被 fully unlock 是因为结构性问题而不是你控制范围外的 unknowable 因素时，你有两个选择——wait and hope，or 你站进去做那个 catalyst。前者是被动 value investor，后者是 engaged owner——两种都合理，看 situation**。

## Abstract Form
当你作为一个 stakeholder 看到一个 entity（公司、组织、团队、关系）的 underlying value 和 realized value 之间有 clear gap，而这个 gap 的来源不是 market sentiment 或 uncontrollable factor，是 **结构性/治理性的 friction**——你面临一个选择：做 passive observer（相信时间会解决）还是做 engaged stakeholder（用 position + influence 帮助 unlock）。两种都合理，不要默认其中一种是唯一正确。选择 engaged 路径的 criterion：**(1) 你对这个 entity 的 underlying quality 有深度判断且判断是 positive**——underlying 必须成立，不然 engaged 只是浪费；**(2) gap 的来源是结构性而不是 unknowable**——你能 identify 是什么在阻止 value realization；**(3) 你有 capability 在你想 engage 的 layer 上真正做贡献**——不要 engage 到你没 capability 的 layer 去；**(4) 你能 restrain 自己不越界 take over**——engaged 是 catalyst 不是 controller，越界会破坏 agency。执行时的关键动作：**focus on governance / incentive / strategic direction 这三个 layer，保持 operational 层面的 humility；所有 engagement 是建议式不是命令式；最终决策权留给 operator；建立 long-term trust-based relationship 而不是 transactional relationship**。关键信号：你看到 structural friction、你有 capability 帮助 unblock、你的 engagement 路径不会破坏 entity 的 agency。诊断问句：**"我 engage 之后能真正帮助 value unlock 吗？还是我只是想 control？如果是后者，back off；如果是前者，进场但保持 catalyst not commander 的角色。"** 区分 engaged ownership 和 controlling ownership，是长期价值关系的分水岭。
